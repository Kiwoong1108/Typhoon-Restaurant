# 태풍반점

![태풍반점](thumbnail.png)

배달 오토바이가 물에 잠긴 태풍반점. 주방장이 인라인을 신고 웍을 든 채 빗속을 달리며 새우볶음밥을 볶아 배달하는 1인칭 세로형 모바일 미니게임 (약 20~25초).

## 조작
- 폰: 좌우로 기울여서 이동 (iOS는 시작할 때 동작·방향 권한 허용) / PC: 마우스 위치로 이동
- 탭(클릭): 웍질. 밥알을 공중에 띄워 웍에 닿는 시간을 멈춤
- 길에 떨어진 새우를 주워 볶음밥에 넣기

## 규칙
- 밥알마다 웍에 닿은 시간으로 익힘 결정: 8초 미만 덜 볶음, 8~13초 노릇, 14초 이상 탐
- 물웅덩이를 밟으면 느려져서 도착이 늦어짐
- 떨어지는 물건에 한 번 맞으면 뒤로 넘어지며 볶음밥이 전부 하늘로
- 25초 안에 도착하지 못하면 밥이 식어서 실패

## 기록 공유
- 결과 영수증 카드를 길게 눌러 이미지로 저장
- "기록 링크 복사"로 만든 링크를 열면 그 사람의 결과 카드가 뜨고, 탭하면 처음 화면에서 새로 도전 (서버 없이 링크 주소에 기록을 담음)

GitHub Pages: Settings → Pages → Branch `main` / root 로 배포
